# Data model v1 design (SQLite)

All primary IDs: UUID/ULID text, foreign keys ON, CHECK constraints, unique indexes; UTC ISO-8601 timestamps, integer money in poisha, local date strings for clinic scheduling. No destructive cascade on clinical/financial parents. Migrations in `schema_migrations(version, checksum, applied_at)`; DB `PRAGMA integrity_check` on restore. WAL, busy timeout, transactional writes; pagination; normalized schema. All user-entered text UTF-8/Unicode. Soft archive rather than delete for clinical entities. Optional columns below are nullable, required columns are NOT NULL; all references indexed.

## Relations (PK `id` unless noted)
- `app_metadata(key PK, value)`, `clinics(id,name,address,phone,email,logo_attachment_id,created_at)`, `settings(key PK,json_value,updated_by FK users,updated_at)`, `printer_profiles(id,name,paper,width_mm,height_mm,margin_mm,orientation,scale,is_default)`.
- `staff(id,name,dob,gender,address,phone,emergency_contact,blood_group,identification_no,photo_attachment_id,department,salary_poisha,joined_on,status,notes)`; `dentists(id,staff_id FK,registration_no,phone,active)`; `dentist_designations(id,dentist_id FK,title,qualification,sort_order)`; `consultation_hours(id,dentist_id FK,weekday,start_time,end_time)`.
- `users(id,staff_id FK nullable,username UNIQUE,hash,status,failed_attempts,locked_until,password_changed_at,created_at)`, `roles(id,name UNIQUE,system)`, `permissions(key PK,description)`, `role_permissions(role_id FK,permission_key FK, PK pair)`, `user_roles(user_id FK,role_id FK,PK pair)`. Effective permissions are union of assigned roles; last owner invariant enforced in service transaction.
- `patients(id,code UNIQUE,name,dob,age_estimate,gender,blood_group,address,phone,emergency_phone,occupation,referral_source,preferred_language,presenting_problem,allergies,medications,notes,assigned_dentist_id FK,registered_at,created_by FK,archived_at)`; `patient_contacts(id,patient_id FK,name,relation,phone,kind)`; `medical_history(id,patient_id FK,recorded_at,author_id FK,condition,details)`; `dental_history(id,patient_id FK,recorded_at,author_id FK,condition,details)`.
- `visits(id,patient_id FK,dentist_id FK,occurred_at,complaint,history,examination,diagnosis,treatment,procedure,advice,follow_up_at,notes,created_by FK,created_at,updated_at)`; amendments as new `clinical_notes(id,patient_id FK,visit_id FK,author_id FK,body,created_at,supersedes_id FK)`; `clinical_findings(id,visit_id FK,tooth_no,notation,description)`; `diagnoses(id,visit_id FK,code,text)`.
- `teeth(id,notation,number,dentition,PK notation+number+dentition)` seed reference only; `tooth_conditions(id,patient_id FK,visit_id FK nullable,tooth_id FK,status,notes,recorded_at,author_id FK,supersedes_id FK)` append-only, current status derived from latest event; `treatment_catalog(id,code UNIQUE,name,category,description,price_poisha,duration_min,active)`; `treatments(id,patient_id FK,visit_id FK,catalog_id FK nullable,tooth_condition_id FK nullable,name_snapshot,price_snapshot_poisha,dentist_id FK,performed_at,notes)`.
- `medicines(id,name,generic,form,strength,active)`; `prescriptions(id,patient_id FK,visit_id FK nullable,dentist_id FK,patient_name_snapshot,dentist_name_snapshot,dentist_credentials_snapshot,complaint,oral_exam,relevant_exam,diagnosis,advice,created_at,created_by FK,status)`; `prescription_items(id,prescription_id FK,medicine_id FK nullable,sort_order,name_snapshot,generic_snapshot,form_snapshot,strength_snapshot,dose,frequency,timing,food,duration,quantity,instructions,prn,notes)`.
- `appointments(id,patient_id FK,dentist_id FK,start_at,end_at,type,reason,status,notes,remind_at,created_by FK,created_at)`; `appointment_events(id,appointment_id FK,old_status,new_status,at,actor_id FK)`; `queue_entries(id,patient_id FK,appointment_id FK nullable,dentist_id FK,clinic_date,number,arrived_at,status,called_at,completed_at)` unique active patient/date enforced in transaction/partial index; `referrals(id,patient_id FK,visit_id FK nullable,source,doctor,specialty,facility,reason,referred_on,follow_up_on,status,notes)`.
- `invoices(id,number UNIQUE,patient_id FK,patient_code_snapshot,patient_name_snapshot,issued_at,status,subtotal_poisha,discount_poisha,total_poisha,created_by FK,finalized_at,voided_at,void_reason)`; `invoice_items(id,invoice_id FK,catalog_id FK nullable,description_snapshot,quantity,unit_poisha,line_total_poisha,sort_order)`; `payments(id,invoice_id FK,patient_id FK,paid_at,amount_poisha,method,reference,notes,received_by FK,reversed_by_payment_id FK nullable)`; totals from sum of effective payments; reversing entry negative, never edit existing receipt.
- `expense_categories(id,name UNIQUE,active)`, `income_categories(id,name UNIQUE,active)`, `accounting_transactions(id,category_type,category_id,amount_poisha,occurred_at,method,description,reference,attachment_id FK,created_by FK,source_payment_id FK nullable)` payment-linked income generated once inside payment transaction; reversal generates offset.
- `suppliers(id,name,contact,phone,email,address,notes,active)`; `inventory_items(id,sku UNIQUE,name,category,supplier_id FK,unit,purchase_price_poisha,price_poisha,reorder_level,location,notes,active)`; `inventory_lots(id,item_id FK,supplier_id FK,purchased_on,batch,expires_on,quantity_initial)`; `inventory_transactions(id,item_id FK,lot_id FK nullable,kind,quantity_delta,unit_cost_poisha,occurred_at,actor_id FK,reason,reference)`; stock is sum of deltas, guarded transactionally against negative totals.
- `attachments(id,patient_id FK nullable,entity_type,entity_id,original_name,stored_name UNIQUE,mime,byte_size,sha256,created_at,created_by FK)`; files in random ID paths, not embedded BLOBs; `notifications(id,kind,severity,dedupe_key UNIQUE,title,body,created_at,read_at,recipient_id FK)`; `audit_logs(id,at,actor_id FK nullable,role_snapshot,action,entity,entity_id,context_json,result)` append only to ordinary roles; `backup_records(id,created_at,path,manifest_hash,schema_version,result,created_by FK)`; `timeline_events(id,patient_id FK,kind,entity_id,at,summary,author_id FK)` atomically inserted at each source change.

Indexes: patient code/phone/name (and FTS5 normalized search index with triggers); visits(patient_id,occurred_at DESC); appointment(dentist_id,start_at,status), appointment(patient_id,start_at); queue(clinic_date,status,number); prescription(patient_id,created_at); invoice(patient_id,issued_at), invoice(issued_at), payments(invoice_id,paid_at), payments(paid_at); accounting(occurred_at,category_type); inventory transactions(item_id,occurred_at), lots(expires_on); timeline(patient_id,at DESC); audit(at DESC,actor_id). Report joins aggregate at source then page; exports stream rows with permission checked before query. Referential restrict prevents orphan clinical history. Snapshot fields preserve legal/document context when masters change.
