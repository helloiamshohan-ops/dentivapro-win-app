# UI and interaction contract

Premium clinical: ink `#142C39`, secondary `#526775`, muted `#71828C`, teal `#087E83`, deep teal `#075D64`, accent sage `#DCEFED`, canvas `#F5F8F8`, surface `#FFFFFF`, elevated `#FFFFFF`, border `#DBE4E7`, success `#14805B`, warning `#A76015`, danger `#B23746`, info `#326D9D`, disabled `#A1AFB6`, focus `#166EA6`, hover `#E8F3F2`, active `#DAEAE9`. Contrast ≥4.5:1 body, ≥3:1 non-text. No color-only status. Prefer bundled OFL Latin and Bengali fonts (e.g. Noto Sans, Noto Sans Bengali) for stable offline input/print. Scale: display 32/40, page 26/34, section 20/28, card 16/24, body 14/22, small 12/18, label 12/16, numeric 28/36, tabular 13/20. 4/8px rhythm; radius 10–16; 44px targets; visible focus ring. Reduced motion disables transitions.

Shell: fixed 228px/72px collapsible left rail with icon+tooltip, section groups Practice/Clinical/Billing/Administration, sticky top bar with clinic, Dhaka date, search, notifications, user/role, lock. Main max readable width where appropriate; list tables paginate, sticky headers, horizontal scrolling only within wide tables. Dashboard responsive 3×2 at wide widths, 2 columns medium, 1 narrow. Responsive breakpoints 1280, 960, 700. At 1280×720 all primary actions reachable with vertical scroll; modal max-height 90vh. Forms validate inline with summary; async actions loading/disabled, success toast, actionable error with retry. Empty state with real next action. Confirm destructive actions with distinct danger styling and reauth.

Screen inventory (each requires loading/empty/error/success, responsive and permission test): activation, wizard, login/lock, dashboard, patients/list/profile/visit/chart, appointments calendar/list/day/week, queue, treatment catalog, prescriptions/list/edit/preview, invoices/list/edit/preview, payments/history, inventory/items/transactions/suppliers, accounting/transactions/reports, staff/users/roles, backup/restore, settings tabs, notifications, search/results, reports/exports, About. Hide or disable only after service permission checks. No decorative fake chart or inactive navigation. Shortcuts: Ctrl+K search, Ctrl+Shift+P new patient, Ctrl+Shift+A appointment, Ctrl+L lock where OS/browser permits, Escape closes dialog; document conflicts and keep browser-native Ctrl+P for print preview. Semantics, labels, focus return, screen-reader announcements, tooltip for icon-only controls; avoid focus traps outside dialogs.

Icon concept: vector shield/tooth formed by negative-space D in deep teal on pale sage, centered in square, geometrically simple at 16px. Rasterize at 16/24/32/48/64/128/256, inspect optical center, package multi-size ICO. No unauthorized artwork.
