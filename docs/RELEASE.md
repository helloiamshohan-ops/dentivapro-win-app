# Installer, CI and release policy

Windows x64 Electron Builder NSIS installer, per-machine or per-user as configured, creates Start Menu/optional desktop shortcut, uninstall entry and icon. Binaries in Program Files or user app folder; never DB/attachments in binary directory. Uninstaller preserves `%APPDATA%/DentivaPro`, `%LOCALAPPDATA%/DentivaPro` and external backups by default, with clear retention notice; optional data removal is explicit and separately confirmed. Reinstall must recognize existing schema and preserve activation/data. Offline installer bundles Chromium/Node; no runtime download at first run. No automatic network updater. Version chosen only after acceptance; no tag/release until validated.

PR CI should run on Windows and fail for lint, types, unit/integration, security audit or packaging failures; protected main branch checks configured in GitHub if repository permissions allow. Release on manual dispatch only after signed-off evidence: checkout exact tested SHA, run all gates, build NSIS, validate installer artifact hash and architecture, publish artifact; create GitHub release/tag from session branch only after actual validation. If release unavailable, copy **validated installer**, not source, to `dist/`. Never create dummy executable. Certificate signing is conditional on certificate availability and unsigned status is explicitly disclosed. Documentation includes support/restore instructions and lockfile-derived notices with license compatibility recorded, not inferred.
